# Snapzen

> 强大，但克制。一款免费开源的跨平台截图工具。

Snapzen 的出发点很简单：现有的截图工具里，**能力最强的不好用，最好用的不免费，免费的又只有半个平台**。

- ShareX 功能无敌，但只有 Windows，配置界面劝退新手
- CleanShot X 体验最好，但只有 macOS，而且要付费
- Snagit 专业全面，但订阅制，且偏重团队文档场景
- Lightshot 够快够简单，但功能到此为止，且已多年缺乏维护
- Greenshot 稳妥轻量，但 UI 停留在上个时代，macOS 版还要单独收费

Snapzen 想做的事：**取五者之长，砍掉各自的包袱**，做一款默认好用、需要时够强、永远免费、三平台一致的截图工具。

---

## 取其精华

| 借鉴对象 | 我们要拿走的 |
|---|---|
| **ShareX** | 可编排的捕获后工作流（截图 → 处理 → 上传 → 复制链接 全自动）、丰富的上传目标、OCR |
| **CleanShot X** | 截图即入剪贴板、悬浮截图托盘（不再糊满桌面）、克制精致的标注与打码体验 |
| **Snagit** | 滚动长截图、历史截图库与检索 |
| **Lightshot** | 一个快捷键到框选标注完成的极短路径，零学习成本 |
| **Greenshot** | 轻量的常驻开销、灵活的导出目标 |

## 弃其糟粕

明确**不做**的事，和要做的事同样重要：

- **不做单平台**：Windows / macOS / Linux 一等公民，行为与快捷键保持一致
- **不做付费墙**：不设 Pro 版，不做功能阉割，不搞订阅
- **不强绑云**：本地优先。云上传是可选的、可自建的（S3 / WebDAV / 自定义 HTTP），不是必经之路
- **不做账号体系**：用截图工具不需要注册
- **不做遥测**：默认不采集任何数据
- **不把复杂度摊给用户**：高级能力藏在需要时才出现的地方，默认路径必须一键完成

## 规划中的能力

- [ ] 区域 / 窗口 / 全屏 / 多显示器捕获
- [ ] 标注：箭头、文字、序号标记、高亮、马赛克与模糊打码
- [ ] 滚动长截图
- [ ] 截图历史托盘与本地库
- [ ] 可编排的捕获后工作流
- [ ] OCR 文字提取
- [ ] 录屏与 GIF 导出
- [ ] 自定义上传目标（S3 / WebDAV / 自定义 HTTP）
- [ ] 全局快捷键与配置同步

## 技术选型

性能是硬性约束，不是优化项：**常驻内存 < 30MB，快捷键到选区遮罩 < 50ms**。

- **纯 Rust + `egui` / `wgpu`**，不使用 WebView
- 屏幕捕获在各平台直接走原生 API（ScreenCaptureKit / Windows.Graphics.Capture / PipeWire）
- 常驻进程只保留快捷键与托盘，其余能力按需加载

明确否掉了 Electron（常驻 150MB+）和 Tauri（WebView 进程常驻 60–100MB，且冷启动延迟不适合热路径）。完整对比与理由见 [`docs/tech-stack.md`](docs/tech-stack.md)。
