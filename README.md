# PinWall

> 把截图钉在屏幕上。一款免费开源、商用也免费的跨平台截图与贴图工具。

现有的截图工具各有一块做到了极致，但没有一款把它们凑齐：

- **Snipaste** 的**贴图**（截图变成置顶浮窗，随时对照）体验无可替代，但闭源、商用要付费、没有工作流与滚动截图
- **ShareX** 功能无敌，但只有 Windows，配置界面劝退新手
- **CleanShot X** 体验最好，但只有 macOS，而且要付费
- **Snagit** 专业全面，但订阅制，且偏重团队文档场景
- **Lightshot** 够快够简单，但功能到此为止，维护停滞
- **Greenshot** 稳妥轻量，但 UI 停留在上个时代，macOS 版还要单独收费

**没有任何一款产品同时提供「贴图」和「捕获后自动化工作流」。** Snipaste 有贴图没工作流，ShareX 有工作流没贴图且只有 Windows —— 这个交集就是 PinWall 的位置。

PinWall 想做的事：**贴图是一等公民，工作流开箱即用，完全开源，商用免费。**

> **平台说明**：优先支持 Windows 与 macOS。Linux 为实验性支持，仅覆盖 X11 / XWayland —— Wayland 从协议层面禁止客户端设置窗口位置，而贴图恰恰依赖任意坐标定位，详见 [MVP 风险评估](docs/mvp-risks.md#r1-wayland-上贴图基本无法实现--linux-必须降级)。

## 取其精华

| 借鉴对象 | 我们要拿走的 |
|---|---|
| **Snipaste** | **贴图**：把截图钉成置顶浮窗，用于对照与比对 —— 本项目的核心能力 |
| **ShareX** | 可编排的捕获后工作流（截图 → 处理 → 上传 → 复制链接 全自动）、丰富的上传目标、OCR |
| **CleanShot X** | 截图即入剪贴板、悬浮截图托盘（不再糊满桌面）、克制精致的标注与打码体验 |
| **Snagit** | 滚动长截图、历史截图库与检索 |
| **Lightshot** | 一个快捷键到框选标注完成的极短路径，零学习成本 |
| **Greenshot** | 轻量的常驻开销、灵活的导出目标 |
| **Raycast** | 扩展生态模型：核心保持精简，上传目标与集成交给插件 |
| **Paste** | 历史记录做成可视化卡片时间线，而不是文件列表 |

## 弃其糟粕

明确**不做**的事，和要做的事同样重要：

- **不做单平台**：Windows 与 macOS 一等公民，行为与快捷键保持一致（Linux 受 Wayland 协议限制，为实验性支持）
- **不做付费墙**：不设 Pro 版，不做功能阉割，不搞订阅，**商业使用同样免费**（Snipaste 自 2.0 起商用需付费许可，这是我们明确的差异点）
- **不强绑云**：本地优先。云上传是可选的、可自建的（S3 / WebDAV / 自定义 HTTP），不是必经之路
- **不做账号体系**：用截图工具不需要注册
- **不做遥测**：默认不采集任何数据
- **不把复杂度摊给用户**：高级能力藏在需要时才出现的地方，默认路径必须一键完成

## 技术选型

性能是硬性约束，不是优化项：**常驻内存 < 30MB，快捷键到选区遮罩 < 50ms**。

- **纯 Rust**，不使用 WebView
- 窗口与绘制直接走各平台原生 API。macOS 上是 `NSPanel` + CoreGraphics 直绘 ——
  选型文档原本推荐 `egui` / `wgpu`，但遮罩与标注实际只需要「几个矩形加一行字」，
  为此背上一整个 GUI 框架并不划算。选型对比仍见 [`docs/tech-stack.md`](docs/tech-stack.md)
- 屏幕捕获同样走原生 API（ScreenCaptureKit / Windows.Graphics.Capture / PipeWire）
- 常驻进程只保留快捷键与托盘，其余能力按需加载

明确否掉了 Electron（常驻 150MB+）和 Tauri（WebView 进程常驻 60–100MB，且冷启动延迟不适合热路径）。完整对比与理由见 [`docs/tech-stack.md`](docs/tech-stack.md)。

## 状态

**macOS 上已经能完整跑通，Windows 与 Linux 尚未开工。** 原型验证阶段已结束
（六个原型全部有结论，其中两个推翻了原先的架构假设，见 [MVP 风险评估](docs/mvp-risks.md)）。

当前打通的闭环：

```
⌘⇧A → 每屏遮罩 → 拖拽框选（可跨屏）→ 分屏捕获并拼接 → 贴为置顶浮窗
     → 标注（矩形 / 箭头 / 打码 / 文字）→ 烧进像素 → ⌘⇧S 存盘、⌘⇧C 复制
```

想试的话：

```bash
cargo run -p pinwall
```

首次运行需在 系统设置 → 隐私与安全性 → 屏幕录制 中授权。目前只有命令行形态，
尚未打包成 `.app`。

还差的东西，按优先级：**Windows 后端**（`pinwall-platform` 里已留好 trait 与占位实现）、
应用打包、窗口 / 全屏捕获、贴图分组、截图历史。
